
Cloud Biometric Banking System 
     
     A secure cloud-based banking application using fingerprint
authentication for fraud prevention. Developed with Python Flask as final year project. 

Key Features
- Biometric Authentication
      Fingerprint verification using ImageHash algorithm. 
- Secure Transactions
      Login, Balance Check, Fund Transfer with biometric approval.  
- Fraud Prevention
      Blocks unauthorized access using image processing. 
- Cloud Ready
      Built with Flask for cloud deployment. 

Tech Stack
- Backend: Python 3.10, Flask Framework

- Libraries: NumPy, SciPy, PyWavelets, ImageHash, OpenCV

- Frontend: HTML5, CSS3, JavaScript  

- Database: SQLite - `database.db`

 How To Run
1. `git clone https://github.com/mariariyojefrim/cloud-biometric-banking-system.git`

2. `pip install flask numpy scipy PyWavelets ImageHash opencv-python`

3. `python app.py`

4. Open `http://127.0.0.1:5000`
